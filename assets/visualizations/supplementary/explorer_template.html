Every attention head in SSoG is a small mixture of Gaussians over token offsets. This page shows those Gaussians on real validation images, layer by layer, and lets you check the paper's efficiency and robustness results.

Early layers mix a few neighbouring tokens; deeper layers reach further and in specific directions. The belief chart shows at which depth the correct class wins, and the dashed line gives the same curve for a standard ViT trained on the same data.

Fixed vs steered kernels

Same image, patch, depth and head as the explorer above. A fixed kernel depends only on learned parameters, so it is identical for every image and every position. A steered kernel predicts a shift of μ (at most max_offset = 7 tokens), a rescaling of σ and a reweighting of λ from the content of each patch.

Steered models were trained on CIFAR-100 only. Switch the dataset above to CIFAR-100 to compare.

Throughput and peak memory are measured (NVIDIA A40, fp16, inference, each model in its own process, averaged over batch sizes 1 to 512). FLOPs are counted and are the same for all three settings. The FLOPs line is the arithmetic advantage. Where a measured line falls below it, the gap comes from kernel implementation: dense attention runs as a fused kernel, SSoG as plain PyTorch operations.

Forward FLOPs per image

GFLOPs (two per multiply-add) for dim768 models applying a block 12 times; attention includes its projections. The three settings agree to within 0.3 GFLOPs, so one is shown. Element-wise operations are not counted for either operator.

Patch-size robustness

CIFAR-100 Acc@1 of models trained at patch 16 (224 px) and evaluated at patch 14 and 8 without retraining. Rescaled scales μ and σ by the grid ratio so each Gaussian keeps its image-space footprint.

At patch 8 the token grid is 4× larger. Dense attention loses 11 to 20 points; SSoG with rescaled geometry loses 7 to 10.

Attention sinks

A sink is a token that receives much more than uniform attention (sink score, 1 = uniform), is the same token across images (same key), and persists through depth (rollout). Fixed SSoG scores 100% on same key only because its image-independent kernel always peaks at an image corner.

How this page was made

Fixed kernels are computed in your browser from each layer's learned μ, σ, λ and softmax temperature, with the same formula as the model code (checked against PyTorch to within 10⁻⁷). Steered kernels use per-patch atoms recomputed from each layer's input on the shown images, checked against the model's own attention output and stored at 8-bit precision, which changes the maps by about 1% of the attention mass. Class belief applies each model's final normalisation and classifier to every intermediate representation. All numbers in the result sections come from the same result files as the paper's tables and figures.
